Next Coding Task: Prompt Builder

Create or open:

services/prompt.py

We'll build a function with a simple, clean interface:

def build_prompt(question: str, chunks: list[dict]) -> str:
    ...

It will:

Accept the user's question.
Accept the retrieved chunks.
Combine them into a structured prompt.
Return a single string for the chat model.

For example, if retrieve() returns:

[
    {
        "content": "PostgreSQL is an open-source relational database."
    },
    {
        "content": "pgvector enables vector similarity search."
    }
]

build_prompt() will produce something like:

You are a helpful assistant.

Use ONLY the following context to answer the user's question.

Context:

PostgreSQL is an open-source relational database.

pgvector enables vector similarity search.

Question:
What is pgvector?

Answer:

This separation is important because it keeps prompt construction independent of retrieval and answer generation.
