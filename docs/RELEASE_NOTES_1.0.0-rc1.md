# Release Notes — 1.0.0-rc1

RAGHub/SIP v1.0 RC1 freezes product scope around NBA Player Opportunity
Intelligence.

Highlights:

- Append-only Situation lifecycle and reasoning history.
- Evidence/claim/hypothesis/forecast/decision/outcome graph.
- Expanded player windows, splits, advanced features, and qualitative labels.
- Canonical sportsbook market normalization and completeness exclusions.
- Evidence-weighted opportunity ranking with explanations and risks.
- Outcome evaluation, Brier score, calibration, subgroup metrics, and lessons.
- Bounded autonomy budgets, approvals, retries, duplicate prevention, and stop.
- Durable incremental ingestion with degraded cached operation.
- Actionable health diagnostics and request IDs.
- Read-only deterministic NBA replay.
- Backup/restore checksum validation and release documentation.

This candidate is not the final `v1.0.0` tag. See the release checklist for
remaining deployment sign-offs.
