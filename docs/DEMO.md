# Family Demonstration

1. Start the Flask application.
2. Open `/demo/nba`.
3. Point out the `HISTORICAL REPLAY` label.
4. Read the original player-availability observation.
5. Show the expected minutes and usage change.
6. Show DraftKings, FanDuel, and BetMGM normalization.
7. Explain the forecast probability as uncertainty, not certainty.
8. Show why the opportunity ranked and the listed risks.
9. Follow the reasoning trace from Observe through Learn.
10. Show the 22-point outcome, forecast score, and stored lesson.

The replay uses deterministic historical-style fixture inputs, performs no live
network calls, and never places a wager. Its purpose is to demonstrate system
behavior reliably, not claim a real current opportunity.
