# Control Plane Bypass Register

Disposition legend:
- `remove`: delete the bypass path
- `wrap`: keep the feature, but route it through a control-plane contract
- `deprecate`: retain temporarily while migrating callers
- `test-only`: allowed only in tests or fixtures
- `acceptable`: intentionally informational or non-financial
